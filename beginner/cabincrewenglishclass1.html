3
Solving Problems on Board
Read + Fill · Error Correction · Read + Identify · Dialogue Writing
Exercise 1 – Read the cabin notes
A flight attendant has notes about four passengers. Read the flight attendant's sentences and write the correct seat number.
🇧🇷 Uma comissária tem anotações sobre quatro passageiros. Leia as frases dela e escreva o número de assento correto.

Cabin notes:
Seat 12A — passenger is cold.
Seat 14C — passenger needs water.
Seat 18B — passenger has a problem with the seat.
Seat 21D — passenger needs help with a bag.
Exercise 2 – Find and correct the problem
The passenger's line is correct. The flight attendant's response is wrong for the situation. Write the correct response.
🇧🇷 A fala do passageiro está certa. A resposta da comissária não é adequada à situação. Escreva a resposta correta.
Gabarito (respostas possíveis):
1. Do you need a blanket?
2. It's at the back, on the left.
3. Of course. I can help.
4. Do you need some water?
5. Yes. This is your seat.
Exercise 3 – Read and identify the passengers
Read the text, then write the correct seat number for each flight attendant sentence.
🇧🇷 Leia o texto e escreva o número de assento correto para cada frase da comissária.

Flight 205 is very busy today. A passenger in 10A is cold. The passenger in 11C needs some water. In 15B, a passenger has a problem with the seat. A passenger in 17D doesn't feel well. Finally, the passenger in 20A needs help with a bag.
Exercise 4 – Passenger problem cards
Read each situation and write a short mini-dialogue. Try to use at least two useful phrases from the week. Send your dialogues to Teacher Mari!
🇧🇷 Leia cada situação e escreva um mini-diálogo curto. Use pelo menos duas expressões úteis da semana. Envie para a Teacher Mari!
